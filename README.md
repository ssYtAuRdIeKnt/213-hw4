# SDT 213 - Homework 4

## Part 1 - Spring Quickstart
Run `quickstart`, then open:
- `http://localhost:8080/hello` -> `Hello World!`
- `http://localhost:8080/hello?name=Yaroslav` -> `Hello Yaroslav!`

## Part 2 - Baeldung Spring Boot bootstrap
Run `baeldung-bootstrap`, then open:
- `http://localhost:8081/` -> page with `Hello!` and `Welcome to Bootstrap Spring Boot`

Both projects use Java 21 and Maven.
